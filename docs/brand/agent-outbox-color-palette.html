03 / Rules

Keep color purposeful

Named colors may organize caller-supplied content, but they remain supporting signals inside an ink, paper, and amber product.

Callers choose names

Use values such as "blue" or "purple". Raw hex, RGB, HSL, CSS variables, and arbitrary CSS color names are not part of the API.

The product chooses values

The application owns the mapping from each name to its rendered value. The palette can evolve without requiring callers to update stored work.
